# # Spotify SQL Data Analysis Project

## Project Overview
This project analyzes Spotify music data using SQL queries.

## Tools Used
- SQL
- PostgreSQL
- Data Analysis

## Key Analysis
- List all albums and their respective artists
- Top artists by album count
- Music data insights

## Example Query
SELECT DISTINCT album, artist
FROM spotify
ORDER BY album
LIMIT 10;

## Dataset
Spotify music dataset containing albums, artists, and song attributes.
